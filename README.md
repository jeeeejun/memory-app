# 암기장

수업 내용을 외우는 웹앱입니다. 빈칸 추론, 암기 카드, 걷기 음성 모드, 반복 복습, 단원 요약이 있습니다.

- 주소: https://jeeeejun.github.io/memory-app/
- 설치 방법: iPhone이나 iPad의 Safari에서 위 주소를 열고, 공유 버튼을 누른 뒤 '홈 화면에 추가'를 선택하세요.
- 카드 데이터: `data/cards.json`. `예시-`로 시작하는 카드는 연습용이므로 지워도 됩니다.
- 앱 파일을 수정했다면 `sw.js`의 `VERSION` 값을 하나 올려야 기기에 바로 반영됩니다.
- 영어 복습(`english.html`): 어형변화 학습지에서 틀린 문제 위주로 다시 풀기(직접 쓰기·카드), 지문 다시 풀기, 오답노트(PDF 저장). 문제 데이터는 파일 안 `eng-data` JSON에 있고, 새 학습지는 화면의 '추가' 탭에서 붙여넣을 수 있습니다.
- 처음 화면에서 과목을 고르면 그 과목의 빈칸 추론·카드·걷기·요약만 보여요. 오른쪽 위 '과목 바꾸기'로 다시 고를 수 있어요.
- 한국사 데이터는 `tools/history_0304.py`로 만들어요(이번 기준: 빨간 밑줄. 외울 부분의 표시 기준은 매번 정할 수 있어요). 새 사진을 추가하는 방법은 `CLAUDE.md`에 있어요.
- 국어 데이터는 `tools/korean_01.py`로 만들어요(기준: 밑줄·형광펜·손글씨 필기).
- 검수·카드 추가·백업은 본 화면에 없고 따로 있어요: https://jeeeejun.github.io/memory-app/manage.html
