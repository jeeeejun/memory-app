# 암기장

수업 내용을 외우는 웹앱입니다. 암기 카드, 걷기 음성 모드, 반복 복습, 검수 기능이 있고, A4 학습지(빈칸·빡지·문답형)를 PDF로 저장할 수 있습니다.

- 주소: https://jeeeejun.github.io/memory-app/
- 설치 방법: iPhone이나 iPad의 Safari에서 위 주소를 열고, 공유 버튼을 누른 뒤 '홈 화면에 추가'를 선택하세요.
- 카드 데이터: `data/cards.json`. `예시-`로 시작하는 카드는 연습용이므로 지워도 됩니다.
- 앱 파일을 수정했다면 `sw.js`의 `VERSION` 값을 하나 올려야 기기에 바로 반영됩니다.
- 영어 복습(`english.html`): 어형변화 학습지에서 틀린 문제 위주로 다시 풀기(직접 쓰기·카드), 지문 다시 풀기, 오답노트(PDF 저장). 문제 데이터는 파일 안 `eng-data` JSON에 있고, 새 학습지는 화면의 '추가' 탭에서 붙여넣을 수 있습니다.
